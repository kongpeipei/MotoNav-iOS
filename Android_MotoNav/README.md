# 摩托导航卫士（MotoNav）

一款自包含的安卓摩托车骑行提醒 App，**无需任何地图/导航 SDK 或 API Key**，可直接用 Android Studio 打开构建。

## 功能
- 定位跟随：GPS 实时显示当前位置（自定义地图视图）
- **闯红灯拍照提醒**（红点）
- **限行 / 禁摩路段提醒**（黄点）
- **车道违章拍照提醒**（青点）
- 接近提醒：进入点位半径自动**语音播报（TTS）** + 顶部状态 + 系统通知
- 点位管理：列表查看、开关提醒、在当前位置一键添加点位（数据持久化到私有目录）
- **导航选路**：点选点位 →「导航到这里」，用免费 OSRM 服务规划路线并绘制在地图上，显示里程与预计时间（服务不可用时自动降级为直线）
- **手动坐标添加**：直接输入经纬度精确添加点位，方便自定义城市/路线
- **导入 / 导出**：点位以 JSON 文件导出备份，或从文件导入共享点位数据
- **模拟测试**：无 GPS 时也可沿样例路线模拟行驶，验证三种提醒是否触发
- **预置合肥点位**：内置合肥一环/二环禁摩区界、主要高架入口等限行参考点（依据合肥市公安局公开政策），靠近自动语音提醒

## 构建
```bash
# 需要 JDK 11+ 与 Android SDK（compileSdk 33）
./gradlew assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

## 安装运行
1. 手机开启「开发者选项」→「USB 调试」，用 Android Studio 直接 Run；
   或把 `app-debug.apk` 传到手机安装。
2. 首次打开授予定位权限（Android 13+ 还需通知权限）。
3. 点「开始监控」使用真实 GPS；点「模拟测试」在室内验证提醒效果。

## 项目结构
```
app/src/main/
  java/com/motonav/app/
    MainActivity.kt        # 界面 + 定位 + 模拟 + 语音/通知联动 + 路线/导入导出
    data/Poi.kt            # 点位类型(闯红灯/限行/车道拍照)与模型
    data/PoiRepository.kt  # 点位仓库(加载/增删/导入导出/持久化)
    engine/AlertEngine.kt  # 接近判定 + 冷却 + 重新进入
    engine/RouteFetcher.kt # 免费路径规划(OSRM, 无需Key)
    voice/VoiceSpeaker.kt  # 语音播报(TTS)
    ui/MapView.kt          # 自定义本地地图(画网格/点位/当前位置)
    ui/PoiAdapter.kt       # 点位列表
  assets/poi.json          # 示例点位(合肥, 可删除重建)
```

## 重要说明
- 点位数据为**众包式手动维护**，仅作辅助提醒，不保证覆盖所有摄像头；
- 内置合肥一环/二环/高架限行点为**区域边界参考**，坐标基于公开政策估算，请以现场路牌为准，可用「手动坐标」修正；
- 应用升级会重新加载新版内置点位（旧版私人数据保留策略见 PoiRepository 的 appVersion 机制）；
- 请遵守交通法规，本工具仅用于提前留意与合规骑行。
